# Java Stream API Practice Problems

## Description

- Implementation of multiple number-based problems using Java 8 Stream API  
- Application of functional programming concepts in Java  
- Practical usage of Stream operations such as filtering, mapping, sorting, grouping, partitioning, and aggregation  

---

## Problems Included

1. Find the second highest number in a list  
2. Find the first non-repeated number  
3. Identify duplicate numbers in a list  
4. Count the frequency of each number  
5. Find the top three highest numbers  
6. Separate numbers into even and odd groups  
7. Find numbers starting with digit 1  
8. Find common elements between two lists  
9. Group numbers by even and odd categories  
10. Calculate the sum of squares of even numbers  

---

## Technologies Used

- Java 8  
- Stream API  
- Collections Framework  
- Lambda Expressions
